# UTS Pemrograman Web - BwiPlayStation 🎮

## Deskripsi Aplikasi
**BwiPlayStation** adalah aplikasi web berbasis Laravel yang berfungsi sebagai Sistem Informasi Pengelolaan Rental PlayStation untuk wilayah Banyuwangi. Aplikasi ini dirancang untuk mengelola data rental unit PlayStation, informasi cabang, serta profil pengguna tanpa menggunakan database (menggunakan struktur data dinamis array).

## Fitur Utama
- **Dashboard Interaktif**: Menampilkan ringkasan statistik total unit PS, jumlah cabang rental, serta indikator status penyimpanan data.
- **Navigasi Lengkap**: Memiliki menu navigasi utama untuk mengakses halaman Dashboard, Pengelolaan Unit, dan Profil Pengguna yang dipersonalisasi.
- **Pengelolaan Unit**: Fitur untuk melihat dan mengelola daftar status unit PlayStation yang tersedia.
- **Manajemen Profil & Session**: Menampilkan nama pengguna terotentikasi (*firdhan a*) dan menyediakan fitur keluar (*Logout*).
